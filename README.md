# VeraLedger – Tax Filing & Accounting Website

A responsive multi-page frontend concept built with HTML, CSS, JavaScript, Bootstrap 5 and Bootstrap Icons.

## Run
1. Extract the ZIP.
2. Open `VeraLedger/index.html` in a browser.
3. Internet connection is needed for Bootstrap, Bootstrap Icons, Google Fonts and remote Unsplash photos.

## Included pages
- Home (`index.html`)
- Home 2 (`home2.html`)
- About Us (`about.html`)
- Services (`services.html`)
- Service Detail (`service-detail.html`)
- Blog (`blog.html`)
- Blog Detail (`blog-detail.html`)
- Contact (`contact.html`)
- Login (`login.html`)
- Register (`register.html`)
- Client Dashboard (`dashboard.html`)
- Admin Dashboard (`admin.html`)
- Terms (`terms.html`)
- Privacy (`privacy.html`)

## Shared features
- Common navbar and footer injected from `js/main.js`
- Responsive mobile navigation
- Profile dropdown with login, sign up, admin and client dashboard links
- Light/dark theme toggle
- LTR/RTL direction toggle
- Responsive layouts and demo forms

## Important
This is a frontend UI prototype. Forms, authentication, payments, document upload persistence, admin actions and client data are not connected to a backend. The file picker on the dashboard is for UI demonstration only. Do not upload real PAN, Aadhaar, bank or tax documents to this demo. Before production, implement secure authentication, authorization, encrypted private file storage, server-side validation, audit logging, privacy notices and compliant data retention.

The brand name, email, phone number, address, dates and dashboard figures are placeholders for the prototype. Replace them with verified company information before publishing. Example email uses `.example` and is not deliverable.
